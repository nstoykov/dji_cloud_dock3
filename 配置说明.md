# Configuration Guide

This document explains the parameters that need to be configured in the project. All configuration entries have been replaced with placeholders. Please configure them according to your actual environment before deployment.

---

## 1. Database Configuration

**File location:** `source/backend_service/sample/src/main/resources/application.yml`

```yaml
spring:
  datasource:
    druid:
      url: jdbc:mysql://[YOUR_MYSQL_HOST]:3306/cloud_sample
      username: [YOUR_MYSQL_USERNAME]
      password: [YOUR_MYSQL_PASSWORD]
```

**Required configuration:**
- `[YOUR_MYSQL_HOST]`: MySQL server address
- `[YOUR_MYSQL_USERNAME]`: MySQL username
- `[YOUR_MYSQL_PASSWORD]`: MySQL password

## Security Recommendations

1. **Do not commit configuration information to version control**
2. **Use environment variables or configuration management tools**
3. **Rotate passwords and keys regularly**
4. **Use strong passwords**
5. **Restrict access to databases and services**
6. **Enable SSL/TLS in production environments**

---

## Configuration Steps

1. Copy the configuration template file (the `.example` file)
2. Edit the configuration file and replace all `[YOUR_*]` placeholders
3. Verify all configuration items are correctly filled in
4. Test the service connections
5. Start the application

For detailed deployment instructions, please refer to `README.md`.
